## Overview

A Retrieval-Augmented Generation (RAG) Q&A chatbot system built with Python, Streamlit, ChromaDB, and Google Gemini API. ## Components

### 1. Web Application (`app.py`)
- **Purpose:** Streamlit-based user interface for uploading/selecting documents, asking questions, and displaying chat history with citations.
- **Location:** `app.py`
- **Dependencies:** `streamlit`, `rag_pipeline.py`, `config.py`

### 2. RAG Pipeline (`rag_pipeline.py`)
- **Purpose:** Orchestrates similarity search against ChromaDB and formats prompts for Google Gemini API to generate accurate document-grounded answers.
- **Location:** `rag_pipeline.py`
- **Dependencies:** `google-genai`, `chromadb`, `config.py`

### 3. Document Ingestion (`ingest.py`)
- **Purpose:** Reads PDF documents from `data/documents/` using PyMuPDF, extracts text, performs chunking, and persists embeddings to ChromaDB.
- **Location:** `ingest.py`
- **Dependencies:** `pymupdf`, `chromadb`, `config.py`

### 4. Configuration (`config.py`)
- **Purpose:** Manages API keys, model parameters, embedding model specifications, chunk sizes, and vector DB paths.
- **Location:** `config.py`
- **Dependencies:** `python-dotenv`

## Data Flow

1. **Ingestion Phase:** PDFs in `data/documents/` -> `ingest.py` extracts text via PyMuPDF -> Text chunking -> Generate embeddings -> Store in ChromaDB vector collection.
2. **Query Phase:** User inputs question in `app.py` -> `rag_pipeline.py` embeds query -> Similarity search in ChromaDB to retrieve relevant chunks -> Construct context-augmented prompt -> `google-genai` calls Gemini model -> Answer streamed back to `app.py`.
